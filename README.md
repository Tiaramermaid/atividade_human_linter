# The Human Linter

## Sobre a atividade
Esta atividade tem como objetivo simular um processo de **Code Review** utilizando **GitHub Pull Request**, reforçando a importância da revisão humana na identificação de erros de lógica e de estilo em um código-fonte.

A proposta foi realizada em dupla, com a seguinte dinâmica:

- **Dev**: responsável por criar funções simples em Python contendo **erros propositais**
- **Revisor(a)**: responsável por analisar o código **sem executá-lo**, identificando problemas e registrando observações no Pull Request

---

## Objetivo
Praticar conceitos importantes de qualidade de software e colaboração em equipe, como:

- uso de **Git** e **GitHub**
- criação de **branch**
- abertura de **Pull Request**
- revisão manual de código
- identificação de erros de **lógica**
- identificação de erros de **estilo** com base no **PEP8**
- correção do código após feedback da revisão

---

## Estrutura do projeto
O projeto contém os seguintes arquivos:

- `atividade.py` — arquivo principal com uma função criada para a atividade
- `media_notas.py` — arquivo adicional com outra função para revisão
- `README.md` — documentação da atividade

---

## Fluxo da atividade
A execução da atividade seguiu as etapas abaixo:

1. Criação de um repositório no GitHub
2. Criação de uma branch específica para desenvolvimento
3. Implementação de funções simples em Python com erros propositais
4. Commit e push do código para o GitHub
5. Abertura de um Pull Request
6. Revisão manual do código pela dupla, sem executar as funções
7. Registro dos problemas encontrados no PR
8. Correção dos erros apontados
9. Commit final com as correções
